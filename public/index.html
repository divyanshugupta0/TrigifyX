Payload Parameters

Field Type Required Description
alert_type string Yes Type of alert. One of: intrusion, access_control, camera_motion, fire_safety, system_health, server_monitoring, load_limit, custom
severity string Yes Severity level. One of: low, medium, high, critical
title string Yes Short alert title shown in Telegram
message string No Detailed alert message/body
source string No Source identifier, e.g. camera_7, sensor_12
timestamp string No ISO 8601 event time, e.g. 2026-07-25T14:30:00Z
metadata object No Additional key/value data specific to your security system
